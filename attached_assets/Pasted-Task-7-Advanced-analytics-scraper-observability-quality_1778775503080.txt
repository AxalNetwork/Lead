Task 7 — Advanced analytics, scraper observability, quality & value metrics
Expand the analytics surface. Add a new migration 040_analytics_v2.sql:
CREATE TABLE lead_quality_snapshots (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  lead_id INTEGER NOT NULL,
  snapshot_date TEXT NOT NULL,
  completeness REAL,
  freshness_days INTEGER,
  provider_count INTEGER,
  confidence REAL,
  quality_score REAL,
  created_at TEXT DEFAULT (datetime('now'))
);
CREATE TABLE source_kpis_daily (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  metric_date TEXT NOT NULL,
  source_domain TEXT NOT NULL,
  pages_fetched INTEGER,
  pages_blocked INTEGER,
  leads_found INTEGER,
  verified_added INTEGER,
  avg_quality REAL,
  cost_usd REAL,
  UNIQUE(metric_date, source_domain)
);
CREATE TABLE pipeline_kpis_daily (
  metric_date TEXT PRIMARY KEY,
  jobs_run INTEGER,
  jobs_failed INTEGER,
  leads_created INTEGER,
  leads_enriched INTEGER,
  leads_approved INTEGER,
  provider_cost_usd REAL,
  browser_render_minutes REAL,
  proxy_gb REAL,
  captcha_hits INTEGER
);

Quality score formula (document in code):
quality_score =
  0.30 * completeness
+ 0.20 * verification_score
+ 0.15 * provider_corroboration
+ 0.15 * freshness_score
+ 0.10 * persona_priority_match
+ 0.10 * track_record_density
All weights live in apps/worker/src/scoring/config.ts so they're easy to tune.
