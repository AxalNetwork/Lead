Task 16 — Better individual profile scraper
The user reported only 7 leads from those firm-list URLs. After Task 14 fixes the list ingest, also harden the per-person extractor so when given a single LinkedIn/Crunchbase/Twitter/personal-site URL it returns useful data instead of one row of metadata.
Replace apps/worker/src/scraper/parsers/generic.ts with parsers/profile.ts that auto-detects profile types and dispatches:
linkedin.com/in/{slug} → never fetch directly. Use Task 4 search-engine discovery to grab the public snippet from search results (title + meta description usually contain headline, current role, location). Tag meta_json.linkedin_snippet_only=true.
crunchbase.com/person/{slug} → fetch via Task 5 tiered fetcher (Crunchbase is bot-protected). Parse the embedded <script id="__NEXT_DATA__"> JSON; extract person.identifier, current_title, primary_organization, location, social handles.
x.com/{handle} or twitter.com/{handle} → fetch via Nitter mirror (nitter.net/{handle}); parse profile bio, location, website, joined date, follower count.
github.com/{user} → fetch via GitHub's public REST API (api.github.com/users/{user}); pull bio, company, location, blog, twitter_username.
{personal-site} → use the same 8-strategy extractor from Task 15's personExtract.ts applied to a single-person page; look additionally for /now, /about, /contact subpages.
crunchbase.com/organization/{slug} → route to a new firm.ts parser that returns a FirmCandidate instead of a person.
signal.nfx.com/... → gated. Reject the job with error='gated_source_use_manual_paste'.
Add a fanout step: after parsing the primary URL, queue up child kind='url' jobs for every outbound link the profile exposes (personal site → discover the rest of their footprint). Cap depth at 1.
Add unit-style tests in apps/worker/test/profile-fixtures/ with HTML fixtures of each profile type so the parsers don't silently break when the source changes layout.
Update Task 1's pipeline.ts to default to parsers/profile.ts instead of generic.ts when no specific parser is configured.
Acceptance criteria:
Pasting a Crunchbase person URL into the Start Scrape panel produces a lead with at least name, current title, primary firm, and one social URL.
Pasting a personal site URL produces a lead with name + at least one contact channel.
A test mix of 20 mixed profile URLs produces ≥ 18 useful leads (≥ name + ≥ 1 channel each).
