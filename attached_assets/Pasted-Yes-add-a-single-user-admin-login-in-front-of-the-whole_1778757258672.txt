## Auth approach

Use Cloudflare Access as the outer gate for the entire app, with only your email on the allow list. Cloudflare Access supports one-time PIN login to approved email addresses, and Access policies are deny-by-default unless a user matches an Allow rule, which is ideal for a one-user admin system.[5][1]

Recommended setup:
- Protect `app.axal.vc` or another custom domain that fronts the Jekyll dashboard.
- Protect `api.axal.vc` for the Worker API with the same Access policy.
- Allow only your exact email, not “everyone with OTP,” because Cloudflare documents that using login method alone can unintentionally open access too broadly.[2][5]

## Analytics design

Use two analytics layers:
- **Platform analytics** inside your app, stored by your own backend, for business metrics such as jobs, leads, approvals, exports, and source performance.
- **Traffic analytics** from Cloudflare Web Analytics for page views and performance, plus optional Workers Analytics Engine for custom event telemetry from the Worker layer. Cloudflare Web Analytics provides privacy-first site metrics through a beacon, and Workers Analytics Engine is meant for custom high-cardinality analytics written from Workers and queried later.[6][7][8]

## Recommended final architecture

The best final shape is:
- GitHub Pages/Jekyll for the static admin UI.
- Cloudflare Access in front of the dashboard and API.
- Cloudflare Workers for API, scraping, verification, export logic.
- Cloudflare D1 for operational data and dashboard aggregates.
- Cloudflare Queues for background processing.
- Cloudflare Web Analytics for traffic/performance.
- Workers Analytics Engine for custom operational telemetry.[9][10][2][6][7]

One important implementation note: because you only have one user, you do **not** need to build a full username/password system inside the app. Cloudflare Access already gives you the gate, session handling, and email restriction, so the app itself can stay “single-tenant admin only” and simply trust the authenticated upstream identity.[2][5][1]
