Profile

Pass ?entity=<id> or ?table=firms&ref=<id> in the URL to scope this view.

How this works. Profile type, ideology axes, interests, and the public-persona summary are inferred by Workers AI from the entity's news mentions, government appointment rows, and political donation rows. Ideology axes stay null when there isn't enough public evidence — we never default to "centrist". Influence axes are derived (not AI). Operators can pin any type or ideology value via POST /api/profile/<id>/override.
